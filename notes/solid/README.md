## 範圍與缺件

已盤點本機分享包與官方PSI/NTRS／原始出版物。219份BASS來源包含125份影像ProofSheets；Saffire/BRE的103份去重文件也不等於全部精讀。缺原始數值、時基或精確試次連結者列為索引／待補；完整文獻與數據保留離線。
