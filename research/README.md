# Research source layers

`raw_sources.zip`: 21 exact NASA source tables referenced by standardized.csv, plus 18 separately labeled derivation inputs. These are not the full instrument/video archive. SOURCE_INDEX.json records hashes and source-relative paths.

`PAPER_INDEX.json`: 21 linked source IDs, 20 distinct locally available PDF files. PDF bytes remain in the separate offline reference package; DOI/NTRS links remain in the runtime catalog.
