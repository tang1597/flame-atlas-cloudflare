## 1. NASA 題目的核心交付

建立**互動式、SI 驅動的網頁 dashboard**，讓使用者可以理解原本難找、難比較、難解讀的 NASA PSI 燃燒研究，對研究進行**摘要、排序、解讀**，產生**載人太空探索的消防洞見**。

消防主軸是 **prevention / detection / suppression（預防／偵測／抑制）**。分析最後應回答具體火災問題：什麼情況危險、NASA 實驗支持什麼判斷、可以據此提出什麼策略或設備構想，以及還需要驗證什麼。

主要適用情境：太空船、太空站、月球與火星基地、加壓車艙等載人環境。**火箭與推進劑消防一般超出現有 PSI 研究範圍**，不能把逆向推進或發動機燃燒當作主要成果。

## 2. 題目建議的能力與選做事項

原文使用「may consider」建議：找出與載人環境消防需求相關的研究、擷取支援可燃性與火災預測的資料，以及凸顯能啟發下一代消防控制與設備的研究。它**沒有要求完成消防硬體，也沒有要求每個資料集都建立或成功訓練模型**。

Potential Considerations 明確為選做。使用者已要求本專案盡量涵蓋下列事項，因此把它們納入專案方向，但不要反寫成 NASA 的強制條款：

- 受眾包括教授、研究生、大學生、航太研究人員與工程師。
- 顯示研究目的、燃料／材料、試片或燃燒器形狀與尺寸、氧濃度、壓力、氣流等條件，以及同一研究中改變／固定的變數、感測器與量測項目。
- 比較不同研究的相似與差異；共享硬體不代表條件、試次或結果可以直接互換。
- 地球消防應用可以延伸，例如細水霧、煙霧偵測、消防衣與呼吸裝備，但不能取代 NASA 資料本身的分析。

## 3. 研究與消防目的的對應

| 研究 | 題目提供的關係 | 解讀時要保留的差異 |
| --- | --- | --- |
| BASS / BASS-II；Saffire-I / II / III | 布料、塑膠等固體可燃性，支援預防與材料選擇 | 按材料、尺寸、氣氛、流場與量測對照，不能只因同名材料就合併數據 |
| SAME / SAME-R | 微重力煙霧與氣膠量測，支援偵測 | 煙粒性質、輸運與偵測反應需要分開；不能只用火焰大小判斷可偵測性 |
| FLEX | 以 CO2、He 稀釋研究液滴火焰抑制 | 液滴／實驗艙結果的適用範圍不自動延伸為載人艙的安全操作規範 |
| DAFT / DAFT-2 | 與 SAME 共享部分儀器，量測塵埃 | 儀器相關不代表是同一種燃燒試驗 |
| BRE（ACME） | 用氣體燃燒模擬靜止氣氛下的材料可燃性與材料性質關係 | 不可簡化為一般瓦斯器具燃燒研究 |
| 其他 PSI 燃燒研究 | 也可能有消防關聯，直接程度不同 | 排序應根據問題與證據，避免所有研究一律標為直接消防依據 |

## 4. 硬體架構需分清楚

| 架構 | 研究群 | 題目描述 |
| --- | --- | --- |
| ACME / CIR | ACME 六項研究 | 氣體燃料火焰，共用模組化 ACME 硬體 |
| MDCA / CIR | FLEX、FLEX-2、CFI | 液體燃料液滴 |
| MSG 模組化風扇流道 | BASS、BASS-II、SPICE、SLICE | 此群合計涵蓋固體與氣體；使用最初為 SPICE 建置的流道，並非每項都同時研究兩種燃料型態 |

比較或建模前必須核對個別燃料、幾何、氣氛、壓力、流場、重力、量測定義與實驗版本。CFI 與 CFI-G 也不能僅因名稱接近就視為同一實驗架構。

## 5. 氧濃度與壓力：避免把情境變成核定規範

- 題目以太空衣約 4.3 psi、100% O2，以及地球海平面約 14.7 psi 作背景對照。
- 題目預期月球基地／加壓車艙可能採 O2 ≥30%、壓力 ≤10.2 psi 的中間條件，以減少預呼吸時間。這是**題目描述的未來情境**，不是所有基地、車艙或設備已核定的通用設定。
- 高氧與低壓必須分別考慮；不能只用氧百分比、氧分壓或地球結果中任一單量，就宣告材料或設備安全。
- CFI-G 最高 85% O2 指**由球形燃燒器流出的氧氮混合氣**，周圍艙體是氮氣與可燃氣，形成反向火焰；不是整個載人艙充滿 85% 氧。

## 6. 部分重力與地球比較的證據邊界

- 題目快照表示 PSI 當時沒有部分重力燃燒資料，並預期未來加入 LUCI、FM2。引用「目前沒有」時必須標明來源快照；對外聲稱最新收錄狀態前，要另查當時的 PSI 目錄。
- E-FIELD Flames 透過電場作用於火焰離子模擬部分重力相關效應，**不是實際月球或火星重力的量測**。
- 微重力與 1g 結果可以協助理解、在條件合適時約束中間重力行為，但不保證單調插值，更不是已驗證的月／火星預測。
- 微重力最直接改變的是浮力與輸運。分子擴散係數須按溫度、壓力、成分判斷；不要無證據地把所有差異都歸因於 O2 的分子 diffusivity 改變。
- 地球對照要核對同成分、幾何與試驗定義。閃點、煙點等測試指標也要核對方法與輸運條件，不能一律視為與重力無關的內禀物性。

## 7. 使用者加強的專案方向（與 NASA 原題分開標示）

使用者特別強調：**用 NASA 的數據產生消防洞見，提出新的消防產品構想與策略，說清楚哪些操作在太空和地球不同。** 以下是專案需求，不是 NASA 題目額外強制的條款：

- 搜尋流程：自然語言問題 → 相關文獻 → 物理數據 → 最相近實驗；再提供尺寸、流速、壓力、氧濃度、重力等相關追加選項。
- 英文 demo 保持簡潔，支援模型互動與尺度比較；研究、數據、模型與原始來源互相連結。滑桿及火焰尺寸預測是工具，消防用途是判斷方向的依據。
- 預防、偵測、抑制各建立可追溯的完整證據鏈，接回主搜尋與排序；同時查核適用的消防規範與實驗／設備操作限制。
- 文獻呈現可用粗體標題、可搜尋的關鍵句／結論、可選的圖表資訊、DOI 與 NASA 資料連結。引句必須確實存在於來源並區分直接引用與解讀。
- 對照同材料／燃料的地球實驗，以文獻模型、mass balance 或 dynamic model 解釋符合與不符合的條件。以物理與現有證據決定適用範圍。
- 經授權的擬合工作，使用者接受的現行 R² 門檻為 ≥0.85；缺原始資料者標記待補，不計 R²。保留來源擬合、獨立驗證、跨尺寸驗證的差異；不回寫舊分數或把停止的工作標成完成。
- 介面使用清楚的 Pass（綠）／Fail（紅）／Unknown。必須說清楚檢查判據：模型燃燒行為、文件參數範圍、設備條件、或完整安全判定；任一項通過不等於其餘全部通過。

## 8. 每個研究成果的共同驗收問題

建議以此證據鏈檢查成果：

**NASA 資料集／試次 → 可量測的發現 → 物理解釋 → 載人環境火災問題 → 預防／偵測／抑制策略或產品構想 → 驗證需求與限制。**

至少能回答：

1. 使用了哪些 NASA 原始資料與文獻，能否追到試次、條件、單位與圖表？
2. 與使用者消防情境為何相關，與地球條件有何實驗支持的差異？
3. 哪些是直接量測、來源作者的解釋、模型推論、跨條件外推或尚待驗證的提案？
4. 對預防、偵測或抑制產生什麼可具體討論的洞見？還不能回答什麼？

模型高 R²、火焰變小、可見火焰熄滅、參數在文件範圍內，都不能單獨當成完整消防安全、設備合格或產品有效性的證明。
